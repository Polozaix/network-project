# University Network Simulation

A university network-design exercise created using **Cisco Packet Tracer**.

This repository contains the Packet Tracer topology file (`.pkt`) and an accompanying project logbook, both in [`projectFolder/`](projectFolder/).

## How to explore the project

1. Install a compatible version of **Cisco Packet Tracer**.
2. Download the `.pkt` file from `projectFolder/`.
3. Open the file in Packet Tracer and inspect the devices, connections and configured interfaces.
4. Use Packet Tracer's simulation tools and CLI to verify connectivity and understand the network behaviour.
5. See the project logbook for the original university work and supporting context.

## What this demonstrates

The project records practical experience assembling and configuring a simulated network with networking devices, then examining connectivity.

**Scope note:** The specific routing protocols, VLAN configuration and verification outcomes have not been independently validated from the `.pkt` file for this README. Open the simulation and the original logbook to confirm the exact topology and implementation before citing these features on a CV.
